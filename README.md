# mansion-shinsui-roadmap
マンション浸水ロードマップ

浸水のあとに住み続けられるマンションか。住所と手元の情報から、理事会に出せるA4一枚を作るWebアプリです。

流れは四つの段階です。

1. 地図に国のハザードマップを重ね、立地の五つの項目を「リスクあり（確定）」「未確認（調査が必要）」「問題なし」に分けます。データが取れない所は斜線で示します。
2. 構内平面図を読み取り、確かめる場所のピン（ア・イ・ウ・エ）を立てます。説明用の 3D の模型で、水の位置と対策を切り替えると、止まる想定の設備、停電の連鎖の図、時間の流れの表が変わります。
3. 画面を見ながら AI に相談し、A4 の一枚（おもて・裏・別紙）と依頼メモを印刷や PDF で出します。
4. 対策を選ぶと費用の桁、決め方、補助の計算の例が変わり、専門家に相談する文書を作ります。送るのは管理組合です。

## 架空の見本

`web/samples/` の平面図（PDF、PNG、SVG）と点検報告書は、この期間に `scripts/draw_plans.py` で新しく作った架空の見本です。実在の建物の図面や記録ではありません。国の電気設備の浸水対策ガイドラインにある一般的な配置を踏まえて描いています。建物の名前と設備はどれも架空で、見本の住所は町丁の代表点だけを使います。

## 動かし方

Python 3.9 以上があれば動きます。追加のインストールはいりません。

```bash
python3 -m app.server
```

起動したら http://localhost:8000 を開きます。

テストと、公開データが読めるかの確認は次のとおりです。

```bash
python3 -m unittest discover -s tests -t .
```

```bash
python3 -m scripts.check_location
```

## Claude の使い方

API キーを環境変数に入れて起動すると、Claude（`claude-opus-5-5`）が図面の読み取り、相談の答え、文書の文面を担当します。追加のインストールはいらず、標準ライブラリで API を呼びます。

```bash
ANTHROPIC_API_KEY=発行したキー python3 -m app.server
```

判定はプログラムの決まりだけで出し、Claude には変えさせません。水、立入、電気の操作に触れる質問は AI を通さず固定の文を出し、Claude の文は数字と禁止の語を事後に確かめます。キーがないときは、PDF の文字の位置、説明カード、定型の文面で動き、その旨を画面に出します。図面と相談の内容は、キーを設定しているときだけ Anthropic の API へ送ります。

## 使っている公開データ

次のデータをその場で取得し、地図の画像は保存しません。読み取った値を加工して表示しています。

- 国土地理院 住所検索 API、標高 API
- 国土地理院 ベクトルタイル提供実験「地形分類」
- 国土地理院 地理院タイル(淡色地図)
- 出典：「ハザードマップポータルサイト」を加工して作成(重ねるハザードマップのタイル。洪水、内水、高潮)
- 千葉市 浸水履歴一覧表、横浜市 所在別災害索引表(見本の2町丁の、いつ・どこ・種別の事実だけ)
- OpenStreetMap の Nominatim(「調べる」を押したときに1回だけ。© OpenStreetMap contributors)

国土地理院の住所検索は公開の仕様がなく、継続の保証もありません。止まったときは、その旨を画面に出します。

既定で読むのは住所検索で得た町丁の代表点の値で、建物の位置の値ではありません。地図のデータが取れない所は斜線で示し、色がない所と区別します。予報ではなく、現時点の静的な整理です。
