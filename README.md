# mansion-shinsui-roadmap
マンション浸水ロードマップ

浸水のあとに住み続けられるマンションか。住所と手元の情報から、理事会に出せるA4一枚を作るWebアプリです。作成中で、今は住所から地図に国のハザードマップを重ね、立地の五つの項目を「リスクあり（確定）」「未確認（調査が必要）」「問題なし」に分けるところまで動きます。

## 動かし方

Python 3.9 以上があれば動きます。追加のインストールはいりません。

```bash
python3 -m app.server
```

起動したら http://localhost:8000 を開きます。

テストと、公開データが読めるかの確認は次のとおりです。

```bash
python3 -m unittest discover -s tests -t .
```

```bash
python3 -m scripts.check_location
```

## 使っている公開データ

次のデータをその場で取得し、地図の画像は保存しません。読み取った値を加工して表示しています。

- 国土地理院 住所検索 API、標高 API
- 国土地理院 ベクトルタイル提供実験「地形分類」
- 国土地理院 地理院タイル(淡色地図)
- 出典：「ハザードマップポータルサイト」を加工して作成(重ねるハザードマップのタイル。洪水、内水、高潮)
- 千葉市 浸水履歴一覧表、横浜市 所在別災害索引表(デモの2町丁の、いつ・どこ・種別の事実だけ)

国土地理院の住所検索は公開の仕様がなく、継続の保証もありません。止まったときは、その旨を画面に出します。

既定で読むのは住所検索で得た町丁の代表点の値で、建物の位置の値ではありません。地図のデータが取れない所は斜線で示し、色がない所と区別します。予報ではなく、現時点の静的な整理です。
