## 長い版

**誰の、何の困りごとか**
大雨で地下の電気室やポンプ室が水につかると、停電そのものより、水・トイレ・エレベーターが止まることが住民を苦しめます。周りの街が戻っても、建物は戻りません。ほかの建物の例では断水8日・トイレ11日で、給水・排水の制御盤は作り直すのに約2か月かかります。それでも、ハザードマップを確かめた所有者・管理者が52.33%なのに対し、電気設備の浸水対策をしたのは、浸水を経験していない人で6.40%でした。電気室への水の入り道（ケーブルを通す壁の穴など）は、建物を見る管理会社と電気を見る保安法人のあいだに落ちています。

**何をするか**
スマホの4つの画面で進みます。
1. 場所を選ぶと、ハザードマップの色と土地の高さで、水が来る道と凹みを地図で見せます。
2. 構内平面図の上で、水が①前の道路・壁の穴 → ②一番低い床 → ③盤の下端と入る順を見せ、どの機械の部屋が浸かって何が止まるかを出します。「止水板だけ／壁の穴を塞ぐ／盤を高くする」を切り替えると、浸かる部屋が変わります。暮らしが止まるまでは時間の順に並べます。避難の判断は、自治体の地図と警戒レベルに分けます。
3. 管理会社が竣工図で確かめた答えを入れると、構内平面図の部屋の色がその場で変わり、未確認が減ります。
4. 残りの確認を、管理会社への依頼メモ・理事会のA4表裏・費用と補助の目安にして印刷します。

**仕組み**
判定はプログラムの決まりで出し、Claude には変えさせません。分からないことは「未確認」とし、危険とは言いません。Claude（claude-opus-5-5）は、図面の写真から部屋と階を読んで答えの候補を出し、質問に答えます。入れるかは人が決めます。浸水した電気室に入る、電気を戻すといった危ない質問には、AIを通さず決まった文で答えます。

**独自性**
作者の電気保安の実務の目で、点検の項目から抜けやすい水の入り道を、理事が管理会社に頼める問いに変えました。見本の建物と図面はすべて架空で、予報ではなく、現時点の静的な整理です。
