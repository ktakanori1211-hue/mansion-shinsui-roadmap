## 長い版

**誰の、何の困りごとか**
大雨で地下の電気室やポンプ室が水につかると、停電そのものより、水・トイレ・エレベーターが止まることが住民を苦しめます。周りの街が戻っても、建物は戻りません。ほかの建物の例では断水8日・トイレ11日で、給水・排水の制御盤は作り直すのに約2か月かかります。それでも、ハザードマップを確かめた所有者・管理者が52.33%なのに対し、電気設備の浸水対策をしたのは、浸水を経験していない人で6.40%でした。電気室への水の入り道（ケーブルを通す壁の穴など）は、建物を見る管理会社と電気を見る保安法人のあいだに落ちています。

**何をするか**
スマホの4つの画面で進みます。
1. 場所：住所を入れると、「ハザードマップ（国の地図）× 線状降水帯で浸かる型」の掛け算で結論を出します。地図に色がなくても、地形分類が低地の群か、周囲より低いくぼ地か、内水の地図に色があるかを規則で見て、「地図に色はないが浸かる型の土地」を洗い出します。東西200mの標高の断面に建物と深さの帯を重ねた図と、住所の市区町村の補助（率・上限・条件）を添えます。
2. 確かめる：平面図・断面図・単線結線図・給排水設備図などを複数枚まとめて Claude に読ませ、部屋の階・階数・引込み・受電・盤の置き方・排水の放流先の候補を「すべて入れる」で答えに入れます。給水ポンプ室・電気室・借室が何階かを答えた瞬間に、「→ 地下：浸水すると全戸で断水」の一行と最優先の対策が変わります。
3. 止まるもの：建築CAD風の平面図・断面図で、水が①道路 → ②一番低い床 → ③機械の部屋と入る順を再生し、対策「止水板＋壁の穴／さらに盤を高く」を切り替えると、部屋の札が赤「浸水・停止」から緑「止水・稼働」に変わります。2段構えのクリティカル対策（頻発する内水〜1m／万一の川の洪水3〜5m）を、優先順・概算・決議・根拠1行の表で出します。
4. 渡す：管理会社への依頼メモ、理事会のA4縦1枚（左右2段組みの議案書）、単価×個数の費用と東京電力管内の自治体の補助を自動で当てた組合の実質負担・1戸あたりを印刷します。避難の判断は、自治体の地図と警戒レベルに分けます。

**仕組み**
判定はプログラムの決まりで出し、Claude には変えさせません。分からないことは「未確認」とし、危険とは言いません。引込みや盤の形は図面で分かるまで断定せず、国のデータがない内水は理由（排水が追いつかない大雨では色のない区域でも冠水）を添えます。Claude（claude-opus-5-5）は、図面から部屋・階・設備の形を読んで候補を出し、建物名から階数を Web で探し、質問に答えます。入れるかは人が決めます。浸水した電気室に入る、電気を戻すといった危ない質問には、AIを通さず決まった文で答えます。数字は出典を確かめたものだけで、費用は桁の目安、補助は要綱を原文で確かめた制度だけです。

**独自性**
電気主任技術者としての実務の目で、点検の項目から抜けやすい水の入り道（管路口・足元の換気口・床置きの盤）を、理事が管理会社に頼める問いと、理事会で決められる対策に変えました。見本の建物と図面はすべて架空で、予報ではなく、現時点の静的な整理です。
