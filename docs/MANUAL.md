## 2. 画面の流れ

### 今の画面（2026-11-05 一本化）

`http://localhost:8000/` を開くと、画面（`web/index.html`・`start.js`・`start.css`）が出ます。前のかんたん版の入口 `/start.html` も同じ画面を出します。スマホの1列で、1画面に「図1枚・太字1行・ボタン1つ」です。3D の模型と前の「くわしい版」の画面は外しました。右上の小さなリンクで「根拠と資料」（`/sources.html`）を開けます。

1. **場所:** 住所かマンション名で探すか、架空の見本 A・B・C を押します。地図の上に、一番深い浸水の想定（洪水・内水・高潮の深さの帯のまま）を建物の階に置き換えた札を出します（例：「想定しうる最大の大雨で川があふれると 3m〜5m／2階の床を超える深さ」）。深さの区切りの言い方は、国交省「水害ハザードマップ作成の手引き」第3章 3.4.1 の区分（0.5m＝1階の床の高さ、3m＝2階の床の下、5m＝一般的な家屋の2階が水没）に合わせ、出典を札に書きます。一般的な家屋の区分で、マンションの階の高さとは限りません。5m より深い所は「1階を約3m」とした割り算の目安で、その旨を添えます。札の下に、同じ場所のほかの想定（計画規模・内水・高潮・津波）を表で並べ、洪水の想定のときは「水が引くまで」（洪水(想定最大規模)の浸水継続時間）も出します。内水のデータがないときは、わがまちハザードマップ（国土地理院）へ案内します。色がない所は「浸水しないという意味ではありません」と出します。同じ深さの線を、画面2の断面の切り絵にも「この場所の想定」として引きます。地図に、ハザードマップの色（サーバーが色ありと読んだ層）、東西南北50mの標高、高い方から建物へ向かう水の矢印を出し、その下に太字1行（凹みなら「周りより低い凹み」を一番に、次に確かめた立地のリスク、なければ土地の高さ）と、立地の5項目の短い札を出します。自分の建物では、さらに次を出します（2026-11-05）。
   - 地図を押すと、その点を建物の位置として読み直します（町丁の代表点ではなく）。
   - 「何階建て」「地下は ある／ない／分からない」を聞きます。「Web で階数を探す（Claude）」を押すと、建物名と町丁を Anthropic の API に送り、Web 検索で地上・地下の階数を出典つきの候補として探します。人が「この値を使う」を押したときだけ使います。
   - 「この辺りで、大雨のときに道路や敷地が水につかったことはありますか？」を聞きます。答えは判定を変えず、依頼メモで市区町村（下水道の担当）への確認として頼みます。
   住んでいる階を入れて（なくても進めます）「この建物で見る」。
2. **止まるもの:** 3段で、住民に何がまずいかを見せます（2026-11-05）。
   - **どう浸水するか:** 建物を斜めから切った断面の切り絵（見本の階数・地下の有無・機械の部屋から描く説明用の模式）。「▶ 水が入る順に見る」で、水位①②③（サーバーの文のまま）の順に、道路・スロープ・壁の穴から水が入り、機械の部屋が水につかります。止まるかはサーバーの scenario のままで、上の階の窓の明かりが消え、エレベーターに「止」が出ます。下に暮らしの3つ（水・トイレ／エレベーター／家の電気）。
   - **暮らしが止まるまで:** 大雨が近づいたとき → 水が来た当日 → 水が引いた翌朝 → 数日〜1週間 → 約2か月〜本復旧 の5段。表面は段の名前と太字1行（住んでいる階を入れると「8階まで、水もごみも階段で運ぶ」）、目安の文はサーバーの五段の表のまま出典つきで、くわしくは折りたたみ。「この建物の日数ではありません」の一行を添えます。
   - **どこを確かめるか:** 機械のある階の構内平面図に、部屋を判定の色（赤＝止まるおそれ（確かめた）、橙＝未確認（危険という意味ではありません）、緑＝問題なし）で直接塗り、水の入り道を青い矢印で重ねます。
3. **確かめる:** 一番上で「竣工図はありますか？」を聞きます。ない人は、見て分かる3つ（地下へのスロープ・電気室の扉の階・止水板）を答え、依頼メモの「住民の話・見たこと」に載せて進みます（色は変えません）。図面がある人は、平面図を上に貼り付けたまま、管理会社に竣工図で見てもらった答えを、①ポンプの部屋 ②電気を受ける部屋 ③東京電力の変圧器の部屋 ごとに「地下／1階／2階以上／図面にない／まだ」で入れます。答えは今の判定の語（`pump`・`upper:pump`・`absent:pump` など）のまま送ります。入れるたびに平面図の部屋の色がその場で変わって光り、未確認が減り、番号のピンは残りの確認（`top_line.steps`）だけになります。答えだけでは赤になりません（場所のリスクが確定していて、図面で確かめたときだけ赤）。見本でない建物では、「地下」「1階」の答えを部屋の階として送り、②は先に点検報告書で電気主任技術者の名前を確かめます。「図面の写真から読む」で、Claude が部屋と階を読み、答えの候補を出します。
4. **渡す:** 3つの紙を切り替えます。「文で送る（LINE・メールなど）」で、要点の文（町丁までの住所、深さと同じ場所のほかの想定、頼む確認、固定の免責）を、スマホでは共有の画面で、パソコンではコピーで渡します。サーバーには何も送りません。
   - **依頼メモ:** 平面図とピン、残りの確認を電気を知らない人の言葉で、頼む先と一緒に。A4 1枚。
   - **理事会A4:** 表は、太字1行・平面図・暮らしの3つ・理事会で決めること（3行）・大雨が近づいたら（サーバーの文のまま）。裏は、対策の費用の目安と決める場と補助の印、補助の制度、固定の文（免責・浸水実績・予報ではない・費用は見積りに置き換える・対象の範囲・区域の外）。表裏の2枚。
   - **費用・補助:** 対策を「今すぐ／工事が要る／更新と一緒」に分け、費用の幅（サーバーの値のまま）・決める場・補助の印（東京都と千葉市だけ。言い切らない）を出します。A4 1枚。

右下の「質問する」で、どの画面からでもチャットを開けます。窓の上に固定の文と送り先（Anthropic の API を通るか、説明カードで答えるか）を出し、答えごとに Claude／固定の文／説明カードのどれから答えたかを添えます。浸水・停電中の危険な場所への立入・操作・接触の質問は、サーバーが AI を通さず固定の文で答えます。答えが平面図の部屋を指すときは、その部屋を光らせます。

紙に出す住所は町丁までに丸めます。固定の免責は、どの画面でも一番下に、言い換えず畳まずに出し、どの紙にも入れます。

#### くわしい版

### 最初の画面（住所を入れる前）

- 「住民に『うちは大丈夫？』と聞かれたら」の一行、一言「地図の色がなくても浸水する。」、二行目「だから、水が引いた翌朝に何日で水が出るかを、建物で確かめる。」、住民が困ること（水が止まればトイレも風呂も使えず、エレベーターが止まれば高い階は階段）、三つの手順、住所の検索欄、架空の見本 A・B・C のボタンが出ます（一言と二行目は SPEC の決定のとおり。2026-11-04 に戻しました）。
- 住所、マンション名、郵便番号、駅名、現在地、地図を押す、のどれでも場所を選べます。マンション名は、地図に名前がある所か、API キーがあるときに Web 検索で確かめられた所だけを候補にします。

### ① 場所

- **上の一行:** 場所を選んだあとも「地図の色がなくても浸水する。」を場面カードの上に残します。右のカードは「水・トイレ・エレベーターが止まるおそれ」です。
- **天気の場面カード（5枚）:** 台風、線状降水帯、上流の大雨、満潮、地震（津波）。浸水の8つのパターンを、どの場面で重なるかで束ねています。この土地の地図の色や凹みの形に当てはまるパターンの数で、カードが灰・橙・赤になります。カードには「この土地に当てはまる水の来方：3つ」と、何の数かを書き、当てはまる数の多い場面から並べます。
- **時間の再生:** カードを押すと、地図の右上に再生ボタンとスライダーが出ます。
  - 段階1「窪地・深い所にたまる」→ 段階2「低い所から広がる（道路も冠水しうる）」→ 段階3「建物の前に迫る」の順に、水が広がります。
  - 公的な地図に色がある所は深い区分から順に濃い青で、色がない所は標高の低い所から水色の「模式」で広がります。
  - 段階3の境目は、ピンの点が実際に濡れる所から決めています。届かないときは「ピンの点には届かない（安全という意味ではない）」と出します。
  - 段階は順番を見せる模式で、時刻や浸水の速さの予測ではありません。
- **切り替え:** 「凹みの模式を出さない」（公的な地図の色の所だけ広げる）と、「地図の横に、建物の断面図を並べる」は、地図の上の折りたたみ「表示の設定と、地図で詳しく調べる」の中にあります。
- **地図:** 国のハザードマップ（洪水の計画規模・想定最大規模、内水、高潮、津波）を重ねられます。データが取れない所は斜線です。
- **土地の成り立ち（地図の上の一行）:** 国土地理院の地形分類の自然地形と人工地形を、二つの箱に分けず「もとは『旧水部』→ いまは『盛土地・埋立地』」の一行で出します。分類の名前は国土地理院が配る style.js の表（5桁と7桁の番号の両方）から引き、番号は画面に出しません。
- **ピンの案内:** ピンが町の代表点のままのときは、地図の上に橙の枠で「地図で建物の上を押すか、ピンを建物へ動かしてください」と大きく出します。
- **建物名の検索:** 「みどりハイツ幸町」（架空）のように建物名の中に地名の字があっても、それは住所として扱いません。API キーがあるときは Claude の Web 検索で建物名が一致するページから所在地を確かめます。見つからないときは町の候補だけを出し（道の駅・駅・公園などは候補にしない）、ピンを動かすよう案内します。
- **洪水の値:** 立地のカードの大きな値には、計画規模と想定最大規模のどちらの値かを札で添えます（地図の切り替えで別の規模の値も見えるため）。
- **凹みの札:** 「周囲より低い凹み（目安）」は塗りの警告ではなく橙の枠にし、「周囲（北・東・西）より約0.2〜0.5m低い」のように、地図の標高データの値の差を添えます（新しい区切りは作っていません）。
- **土地の形と立地の5項目:** ピンの周りの標高の図（周りが高い凹みでは外からピンへの矢印）と、洪水・内水・高潮・敷地の高低差・市の浸水の記録の三分類。分からないことを危険とは出しません。

### ② 建物

- **理事会で、最初に見る1枚（②の一番上。2026-11-04 作り直し）:** ②を開いて目に入るのはこの1枚だけにし、ほかの欄（次の3つの帯、断面図・3Dの窓、建物の質問、何が止まるか、停電の連鎖）は「くわしく見る」の畳みに入れました。目をやる所は3つです。
  - 何が起きるか：大きな一言と、文字と図形が重ならない断面の絵（「▶ 水が入る様子を見る」で1→3と動く）。
  - あなたの暮らしでは：住んでいる階を入れると「12階まで毎日階段」のように出る。
  - 次の理事会で決めること：「管理会社に、3つの確認を頼む」と、その3つを電気を知らない人の言葉（例：水を送るポンプのスイッチの箱が、床から何cmの高さにあるか）で出し、最初の手の桁と「理事会と管理費で決められることもある」を添える。「管理会社への依頼メモを印刷」「理事会用の表裏1枚を見る」で③の紙へ移る。
- **（前の版）うちのマンションで起きること:** 電気のことをまったく知らない理事・住民が一目で分かるように、専門用語を使わない一枚を置きました（web/glance.js）。
  - 大きな見出し「地下の機械が水につかると、全部の家で暮らしが止まります」と、4つの場面「1. 大雨で、道路に水がたまる」「2. 水が、地下（機械の部屋）に流れ込む」「3. 機械が水につかって、止まる」「4. 外の水が引いても、すぐには戻らない」。押すか「1から順に見る」で、断面の絵の水と「止まる」の印が変わります。
  - 絵では「電気の機械」「水を送るポンプ」「住まいの階の水・トイレ／家の電気／廊下の照明」「エレベーター」だけを描きます。止まる印はサーバーの判定（水の位置③のとき）のままで、分からないもの（家の電気など）は灰色の「？」にします。
  - 「あなたの暮らしでは」に住んでいる階を入れると、「12階まで、毎日階段で上り下りします」のように自分の話として出ます。「戻るまで、長引くことがあります」には、五段の表の文（ほかの建物の例、制御盤の製作の目安）をそのまま出します。

- **作り直し（2026-11-04）:** ②の主役を「水はこの順に入り、こう止まる」の一枚のカードにしました。
  - 大きな窓に、最初は**断面図（水の入り道）**を出します。タブで「3Dで見る」「平面図」「系統図」に切り替えます。前の版の、図面と3Dの2枚のカードはなくしました。
  - **図面のビューアー:** どの図も、ホイールや2本指で拡大し、ドラッグで動かし、「全体」で戻し、「全画面」で画面いっぱいに見られます。自分で入れた PDF や画像の図面も同じです（PDF は高めの解像度で描きます）。見本の図は SVG で出すので、拡大しても字がにじみません。ピンは拡大しても大きさが変わりません。
  - 断面図と平面図は、用紙の余白・凡例・表題欄を外して、図のある範囲に寄せて出します（断面図は基準の座標の focus、平面図は sample.plan_focus）。
  - **時間の物語:** 窓のすぐ下に、再生のボタンと5つの時間の札（大雨が近づいたとき／水が来た当日／水が引いた翌朝／数日〜1週間／約2か月〜本復旧）を並べました。名前はサーバーの五段の表の列と同じです。
    - 当日の中で水が①②③の順に上がり、翌朝は外の道路の水が引いても地下に水が残り、数日後は水を抜いても浸かった機械は止まったまま、という順に、断面図と3Dの水と止まる設備の色が変わります（外の水と中の水を分けて描きます）。
    - 札の下の「暮らしの欄」に、その時間の水・トイレ・風呂、エレベーター、廊下の照明、家の電気の状態を大きく出し、五段の表のその列の文（製作に約2か月、仮復旧まで4〜7日程度、ほかの建物の例など）と、「このとき人がすること」（畳み）を添えます。状態と文はサーバーの scenario のままです。
  - **3D:** 部屋を図面と同じ色（電気＝橙、水＝青、借室＝紫）で塗り、そのほかの部屋と1階は薄くしました。上の階は3階分だけ薄く描き、最初の向きを地下と1階が大きく見える近さにしました。止まる設備は赤です。

- 見本以外では、図面を入れるか、近い建物の形（A・B・C）を選んでから、図面と3Dが出ます。
- **一番上の帯:** 右上に「次へ：③A4・費用」のボタンを置きました。
- **一番上の帯（中身）:** 「水が引いた翌朝、この建物は何日で水が出るか」の下に、「まだ分からない」ではなく「次の3つが分かれば、答えが出ます。」と、何が分かればよいか（ポンプの盤が床から何cmにあるか など）と頼む先・依頼メモの番号を3つまで出します。同じものを A4 のおもての頭にも出します。
- **図面（CAD）:** 平面図、断面図（水の入り道）、系統図（電気と給水）をタブで切り替えます。PDF と DXF も開けます。
  - 画面で読めるように、寸法線と通り芯を外し、部屋を種類で薄く塗り分け（電気の部屋は橙、水の部屋は青、EV・階段は紫、駐車場・車路は灰）、部屋の名前を前の版の2倍まで大きくしました（scripts/draw_plans.py）。色は画面と PDF だけで、DXF には書き出しません。断面図の重ね絵の基準の座標は変えていません。
