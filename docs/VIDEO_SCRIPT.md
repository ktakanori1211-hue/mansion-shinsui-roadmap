# 3分動画の台本（下書き）

提出用のデモ動画の台本です。見どころは②の「理事会で、最初に見る1枚」にしぼります。

## 組み立ての考え方

- 冒頭の15秒で「誰のために・何を・どう解決するか」を言う。
- 見どころは1つ。結果がすぐ出る場面を映す。
- 伝えるのは「何をして・どういう仕組みで・どういう結果が出るか」の3つだけ。文字より絵を多くする。
- 独自性は、電気保安の目で見た水の入り道（壁の穴・ポンプの制御盤）。

ナレーションは約800字です。1秒に5〜6字で読み、画面操作の間（ま）を入れて3分に収めます。

## 撮るときの注意

- 建物は架空の見本（「みどりハイツ幸町」など）で撮る。実在の住所は映さない。
- API キーは画面にもターミナルにも映さない。
- 最後に、A4にある固定の免責の文をそのまま映す。言い換えも省略もしない。
- 「断水8日・トイレ11日」には「ほかの建物の例（建築設備技術者協会の調査など）。この建物の日数ではない」と字幕を付ける。
- 2:33 の段は、作者の実際の立場に合わせて言い回しを直す（今の文は仮）。
