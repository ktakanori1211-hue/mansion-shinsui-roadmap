# 3分動画の台本

提出用のデモ動画（2分58秒）の台本です。2026-11-08 に仕上げた8場面の短縮版のセリフと画面の流れを、そのまま書いています。画面は今の4つの STEP（1 場所 → 2 確かめる → 3 止まるもの → 4 渡す）で、東京電力管内のマンションを対象にしています。

## 組み立ての考え方

- **物語から入る。** 冒頭は機能ではなく、作者（マンションの電気室を点検する電気主任技術者）が現場で見ていることから始める。過去の受賞者は「機能より、あなたの仕事がどれだけ大事かを見せる」「意外な人が作ったことが一番際立つ」と言っていた（セッション第4弾）。第5弾の示唆「みなさんにしかできない課題解決を、持っているデータとナレッジで」も同じ。
- **前と後の対比を3つ。** ①地図に色がない場所でも浸水は起きる → 地形を掛け合わせて洗い出せる。②図面は読めない → 3枚まとめて読むと自動で答えに入る。③AI は危ないことも答えてしまう → 危ない質問は AI を通さず0秒で止め、分からない言葉は図の場所を光らせて説明する。
- **言葉と画面を合わせる。** 各場面の操作は、その操作を話す文の始まりに合わせる（録画は声の文の始まりの時刻に合わせて自動で操作した）。
- **主役は WHY・WHAT のとおり。** 地図に色がなくても浅い水で止まる足元と、理事会で決められる対策。避難の判断は自治体の地図と警戒レベルに任せる。

ナレーションは話し言葉の です・ます調で約1030字。8場面と締めのカード（4.5秒）で全体 2分58秒です。字幕は付けず、数字の強調カードだけを重ねます。画面の住所と建物は架空（「みどり市 みどり町1丁目（架空）」「みどり町マンション（架空）」）で、地図・地形・補助制度は見本の地点（千葉市）の公開データを使い、画面の上の注記でそう明記しています。

## 撮るときの注意

- **作者のこと：** 動画・台詞・画面に個人名は出さない。肩書きは「電気主任技術者」だけ。顔と声以外の個人を特定できるもの（自宅や職場が分かる背景、立ち会った現場の場所・建物・深さ・時期）も出さない。見本の建物を、作者の現場の例として紹介しない（要件 W2・how-024 の特定回避）。
- **住所と建物：** 実在の番地・実在の建物名を出さない。住所は架空の「みどり市 みどり町1丁目（架空）」、建物は「みどり町マンション（架空）」で撮る。地図・地形・補助制度は見本の地点（千葉市）の公開データを裏で使い、そのことを画面の上の注記で明記する。
- **64% の数字：** 強調カードに出典「ウェザーニューズ 2026/9/22」を付ける。64% は記事に書かれた数字ではなく2つの型の合計なので、画面のカードと同じ数字だけを使う。
- **図面の読み取り：** 本物の API キーで、`web/samples/plan_a.png`・`section_a.png`・`system_a.png` の3枚を同時に入れる。同じ画像なら2回目からはキャッシュ（`data/cache/`、公開しない）で一瞬で出る。キーがないときの「見本の図面で試す」は、画面に「読み取りの結果ではありません」と出るので、Claude が読んだ場面には使わない。
- **画面3：** 押す前の水位は①（道路だけ）にしておく。③のまま始めると、押したときに①へ戻って見える。対策は「① 止水板＋壁の穴を塞ぐ」を、平面図（上から）で押す。
- **チャット：** チップを押す（文字を打たない）。Claude が光らせる場所は答えによって変わる（電気室・借室・壁の穴など）。光った部屋は、チャットの窓に隠れない位置まで画面が自動で動く。危ない質問はキーがあってもなくても固定の文になる。
- **APIキー：** 画面にもターミナルにも映さない。右上の「設定」のボタンの欄も開かない。
- **費用の目安：** A4 の数字は、強調カードに「デモ用の架空の建物（96戸）の試算。単価は一般的な目安で、実際は見積りに置き換えます」と添える。
- **免責：** 締めで、固定の免責の文をそのまま映す。言い換えも省略もしない。

## 作り方

- **声：** 作者が場面ごとに8本（v01〜v08）を録音する。頭の無音を約0.45秒にそろえ、長い間（ま）を詰め、音量をそろえてつなぐ。
- **画面：** ローカルで `python3 -m app.server`（8000）を動かし、Playwright（入っている Chrome、1920×1080）で8場面を自動で操作して録画する。押すボタンは押す前にオレンジの枠と吹き出しで示す。各場面の操作は、声の文の始まりの時刻に合わせて行う。冒頭と締めの3Dは、別のページで描いて録画する。
- **仕上げ：** 場面の長さを声に合わせてつなぎ、数字の強調カード（64%・11件・赤→緑・0秒で止める・約1,000万〜2,500万円 vs 225万円）と締めのカードを重ねて、1920×1080・30fps の MP4 にする。
- **録画の注意：** headless の Chrome は窓の大きさを指定しないと、画面の下端が映らない（右下の「AIチャット」のボタンが切れる）。起動のときに `--window-size=1920,1080` を付ける。
