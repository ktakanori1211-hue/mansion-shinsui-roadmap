# 3分動画の台本（下書き）

提出用のデモ動画の台本です。かんたん版（最初の画面、4つの画面）で撮ります。見どころは画面3「確かめる」です。管理会社が図面で確かめた答えを入れると、絵の色が変わり、未確認が 3 → 1 に減ります。

## 組み立ての考え方

- 冒頭の15秒で「誰のために・何を・どう解決するか」を言う。
- 見どころは1つ。答えを入れると、その場で色が変わる場面を映す。
- 伝えるのは「何をして・どういう仕組みで・どういう結果が出るか」の3つだけ。文字より絵を多くする。
- 独自性は、電気保安の目で見た水の入り道（壁の穴・ポンプの制御盤）と、「分からない＝危険」としない色の決まり。

ナレーションは約800字です。1秒に5〜6字で読み、画面操作の間（ま）を入れて3分に収めます。画面はスマホの幅で撮ります。

## 撮るときの注意

- 建物は架空の見本（見本A「うみかぜコート」）で撮る。実在の住所は映さない。
- 画面3の「図面の写真から読む」は、本物の API キーで1回だけ撮る。キーがないときに出る見本の答えには「読み取りの結果ではありません」と出るので、それを Claude が読んだ場面として使わない。
- API キーは画面にもターミナルにも映さない。
- 最後に、画面の下の固定の免責の文をそのまま映す。言い換えも省略もしない。
- 「断水8日・トイレ11日」には「ほかの建物の例（建築設備技術者協会の調査など）。この建物の日数ではない」と字幕を付ける。
- 2:40 の段は、作者の実際の立場に合わせて言い回しを直す（今の文は仮）。
- 見本Aで画面3の順に答えると、赤と緑の両方が出る（②「1階か地下」→ 赤、③「2階以上」→ 緑）。撮り直しても同じ結果になる（API を使わない）。
