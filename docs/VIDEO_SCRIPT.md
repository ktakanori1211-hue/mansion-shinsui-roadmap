# 3分動画の台本（下書き）

提出用のデモ動画の台本です。2026-11-05 に1本にまとめた4つの画面で撮ります。

見どころは2つの場面のつながりです。画面2で、構内平面図の上に水が①②③の順に入り、地下の機械が水につかると全部の家で水・エレベーター・電気が止まる様子と、対策を切り替えると浸かる部屋が変わる様子を見せ、画面3「確かめる」で、管理会社が図面で確かめた答えを入れるたびに、構内平面図の部屋の色がその場で変わる様子を見せます。未確認は 3 → 1 に減り、ピンは残りの確認だけになります。

## 組み立ての考え方

- **冒頭の15秒**で「誰のために・何を・どう解決するか」を言う。
- **見どころは1つの流れ。** 「浅い水で全部の家が止まる」（画面2の平面図の再生）から「確かめると色が変わる」（画面3の平面図）へつなぐ。
- **伝えるのは3つだけ。** 何をして、どういう仕組みで、どういう結果が出るか。文字より絵を多くする（メンターの助言）。
- **独自性。** 電気保安の目で見た水の入り道（壁の穴・スロープ）と、「分からない＝危険」としない色の決まり。危ない質問は AI を通さないことも見せる。

ナレーションは約870字です。1秒に5〜6字で読み、画面操作の間（ま）を入れて3分に収めます。画面はスマホの幅（375px）で撮ります。

## 撮るときの注意

- **建物：** 架空の見本（見本A「うみかぜコート」）で撮る。実在の住所は映さない。
- **住んでいる階：** 見本Aは11階建てなので、住んでいる階は「8」で撮る。
- **答えの再現：** 見本Aで画面3の順に答えると、赤と緑の両方が出る（②「地下」→ 電気室が赤、③「2階以上」→ 借室が緑）。撮り直しても同じ結果になる（API を使わない）。
- **写真の読み取り：** 画面3の「図面の写真から読む」は、本物の API キーで1回だけ撮る。キーがないときは、見本の答えに「読み取りの結果ではありません」と出る。それを Claude が読んだ場面として使わない。
- **チャット：** 2:08 の危ない質問は、キーがあってもなくても固定の文になる（AI を通さない）。答えの下の「固定の文（AIを通していません）」まで映す。
- **APIキー：** 画面にもターミナルにも映さない。右上の「Claude」のボタンの欄も開かない。
- **断水の日数：** 画面2の「武蔵小杉は断水8日・トイレ11日」には、「ほかの建物の例（建築設備技術者協会の調査など）。この建物の日数ではない」と字幕を付ける。
- **1年以上の目安：** 0:42 の「復旧に1年以上の場合も」には、「一般的な目安（建築設備技術者協会の報告書）。この建物の日数ではない」と字幕を付ける。
- **再生の注意書き：** 0:00 の平面図の再生は、画面に出る「実際の浸水速度の予測ではなく、水が順番に入る仕組みの模式です。」が映るように撮る。
- **免責：** 最後に、画面の下の固定の免責の文をそのまま映す。言い換えも省略もしない。
- **2:40 の段：** 作者の実際の立場に合わせて言い回しを直す（今の文は仮）。

## 撮影の手順

画面の録画は作者が行います（このリポジトリの作業では録画できません）。

1. **サーバーを起動する。** `python3 -m app.server` で 8000 を起動します。キーはホームのファイルから読みます。キーの欄やターミナルは映しません。
2. **スマホの幅にする。** Chrome の開発者ツールの端末の表示で、幅を 375px にします。ブラウザの拡大は 100% にします。
3. **録画を始める。** macOS なら Command＋Shift＋5 で、ブラウザの画面の範囲だけを録ります。
4. **場面ごとに撮る。** 上の台本の順に、場面ごとに別の録画にすると撮り直しが楽です。場面を始める前にページを読み込み直すと、最初の状態に戻ります。
5. **写真の読み取りの場面。** 見本Aの平面図の画像（`web/samples/plan_a.png`）を「写真・PDFを選ぶ」で入れます。2026-11-05 に本物のキーで1回読み取っていて、その答えが手元の控え（`data/cache/`、公開しない）に残っています。同じ画像なら API を呼ばずに同じ答えがすぐ出るので、撮り直しても料金はかかりません。
   - 読み取りの結果：電気室・借室・ポンプ室とも「地下1階」。①〜③に「地下」を入れる候補が出ます。
6. **チャットの場面。** 危ない質問は、AI を通さない固定の文になります。答えの下の「固定の文（AIを通していません）」まで映します。
7. **仕上げ。** 場面をつないで3分に収め、「断水8日・トイレ11日」と「1年以上」の字幕と、最後の固定の免責を入れます。
