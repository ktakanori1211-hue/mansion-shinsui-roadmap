# 3分動画の台本（下書き）

提出用のデモ動画の台本です。2026-11-05 に1本にまとめた4つの画面で撮ります。

見どころは画面3「確かめる」です。構内平面図の上で、管理会社が図面で確かめた答えを入れるたびに、部屋の色がその場で変わります。未確認は 3 → 1 に減り、ピンは残りの確認だけになります。

## 組み立ての考え方

- **冒頭の15秒**で「誰のために・何を・どう解決するか」を言う。
- **見どころは1つ。** 平面図の部屋の色が、答えでその場で変わる場面を映す。
- **伝えるのは3つだけ。** 何をして、どういう仕組みで、どういう結果が出るか。文字より絵を多くする（メンターの助言）。
- **独自性。** 電気保安の目で見た水の入り道（壁の穴・スロープ）と、「分からない＝危険」としない色の決まり。危ない質問は AI を通さないことも見せる。

ナレーションは約770字です。1秒に5〜6字で読み、画面操作の間（ま）を入れて3分に収めます。画面はスマホの幅（375px）で撮ります。

- **建物：** 架空の見本（見本A「うみかぜコート」）で撮る。実在の住所は映さない。
